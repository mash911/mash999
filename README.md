# محرر ألبومات سانا

ملفات العمل الكاملة لمحرر ألبوم إنستغرام، ألبوم فيسبوك، التصريحات، مراسل سانا، وقالب العلمين.

- الموقع المنشور: https://29-10-2026temp-album.vercel.app
- المستودع: https://github.com/mash911/mash999
- فرع النسخة الحالية: `main`.
- نسخة ما قبل تحديث 7 نوفمبر 2026: `backup/vercel-before-2026-11-07`.

## الملفات

`app.js` و`index.html` وملفات CSS هي المصدر. يحتوي `assets/` على الصور والخطوط المستخدمة.
مجلد `dist/` هو النسخة الجاهزة للنشر، ويحتوي `index.html` في جذره. لا يحتاج المشروع إلى تثبيت حزم أو خطوة بناء.

`deployment-history.json` يسجل إصدار Vercel الحالي وإصدار الرجوع. يحتوي `scripts/backup-release.ps1`
على أداة إنشاء نسخ ZIP محلية مؤرخة، وتوضح `AGENTS.md` تعليمات التحديث والنشر.

## النسخ الاحتياطية والتحديث

قبل كل تعديل، احفظ نسخة محلية وشغّل `scripts/backup-release.ps1`. وقبل تحديث `main`، احفظ رأسه
الحالي في فرع جديد تحت `backup/`. ارفع التعديلات في commit جديد مع الاحتفاظ بسجل النسخ؛ لا تستبدل التاريخ بالقوة.

بعد التحقق من التعديل، زامن ملفات المصدر مع `dist/`، ثم حدّث GitHub وانشر النسخة على مشروع Vercel نفسه.
عند الحاجة إلى الرجوع، استخدم فرع النسخة السابقة على GitHub أو إصدار Vercel السابق المسجل في ملف النشر.

لا ترفع ملفات الدخول أو مفاتيح API أو `.env` أو مجلد `.vercel/` أو أرشيفات `release-backups/` إلى المستودع.
